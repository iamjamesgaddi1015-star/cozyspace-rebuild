# Your CozySpace media

Put your replacement photos in this folder. Then set their URLs and descriptions in ../../src/media.ts.
Example: a file named kitchen.webp here uses the URL /media/kitchen.webp.

Recommended photos: landscape 1536 × 1024 or larger. WebP, JPEG, PNG and AVIF are suitable.
See ../../MEDIA-GUIDE.md for all slots and the rebuild steps. Existing photos stay in ../images/.
